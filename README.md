# AI BIM Design Review Agent

## Overview

AI BIM Design Review Agent is an AI-assisted system that analyzes BIM metadata and generates architectural design review feedback.

The system bridges the gap between BIM geometric representation and human-centered architectural interpretation.

---

## Motivation

BIM models contain rich geometric and semantic information, but design review still relies heavily on expert interpretation.

This project explores how AI agents can translate BIM information into understandable architectural feedback.

---

## System Architecture

BIM Metadata
↓
Parser
↓
Spatial Rule Engine
↓
Architectural Explanation
↓
LLM Interpretation
↓
Design Review Report


---

## Features

### BIM Understanding

- Model metadata extraction
- View analysis
- Semantic element recognition
- Bounding box analysis


### Design Review

Current rules:

- Unit normalization
- View coverage
- Spatial proportion
- Camera scale


### AI Interpretation

The system uses LLM-based reasoning to transform technical findings into architectural explanations.
